Hardware setup

Unplug USB before changing any wiring. Check every connection against the diagram before plugging back in.

  1. 1

    Plug the UNO into this laptop

    Use the blue USB cable from the kit (a data cable). Close Arduino IDE's Serial Monitor — only one program can use the port.

  2. 2

    Upload the C1 sketch

    Arduino IDE → open arduino/c1_station → Tools › Board › Arduino Uno → Tools › Port → Upload. Close the IDE's Serial Monitor afterwards.

  3. 3

    Photoresistor on A1

    Wire it as shown, then cover the sensor with your hand and shine a phone torch on it. The step passes when the reading moves by at least 150.

  4. 4

    LM35 temperature sensor on A0

    Flat printed face toward you: left leg 5V, middle A0, right GND (same breadboard picture as step 3). If it gets hot, unplug immediately — it is reversed.

  5. 5

    ENS160 + AHT21 module (after soldering and checks)

    Do the multimeter checks in docs/HARDWARE_GUIDE.md §3 first. Then run arduino/i2c_scanner (expect 0x38 and 0x53 or 0x52) and set ENABLE_AHT20 and ENABLE_ENS160 to 1 in the sketch.

  6. 6

    Test the QR code with a second phone

    Open the QR page, scan it with a phone on the same Wi-Fi or hotspot, and send one test response. It passes when feedback arrives.
